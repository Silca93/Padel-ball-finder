# Padel Ball Conditions Guide

A one-page guide to which padel ball suits the air you play in. Pick a city (or search any town worldwide) and the page ranks 31 widely sold balls by how well each is built for that altitude, temperature, humidity and court speed.

- Live weather and worldwide city search from [Open-Meteo](https://open-meteo.com/) (free, no API key)
- 290 built-in cities with monthly temperatures as a fallback
- 13 languages, including right-to-left Arabic
- FIP ball specifications, independent durability tests and sources for every claim

## Run it

It is a single static file: open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, Cloudflare Pages).
